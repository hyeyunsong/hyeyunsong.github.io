2026.11유튜브 댓글 분석 자동화
소개:영상 주소를 시트에 넣고 실행하면 댓글을 모아 AI로 분류하고 분석 리포트 메일을 보내는 n8n Workflow
AI:Claude (워크플로우와 코드 작성), OpenAI API (댓글 분류와 의견 정리)
기술:n8n, YouTube Data API, OpenAI API, Google Sheets, Gmail
담당:기획, 리포트 구성 설계, 분류 기준 검토, 결과 검증, 메일 리포트 디자인
핵심:
  • 영상 주소만 넣으면 댓글 500개 수집부터 리포트 메일까지 자동 처리
  • 분류 결과에서 대상 "기타"가 31%로 높은 것을 발견해 기준 재검토결과: 빠진 항목과 정의를 추가해 기타 33.2% → 3.5%
  • 중립이 절반 가까이 나와 긍정, 부정 기준을 재설계중립은 비율에서 빼고 긍정, 부정만 비교하는 순호감도로 표시
  • 의견 주제가 댓글의 일부만 분류하는 문제를 확인해 주제 정하기와 배정을 분리결과: 의견 주제에 담긴 댓글 15% → 69%
  • 결과는 그대로 두고 프롬프트와 코드 최적화를 지시해 토큰 절감결과: 배치 크기와 추론 강도 조정으로 출력 토큰 약 55%, 이후 25% 추가 감소
  • 구글 시트로는 결과가 잘 안 읽혀 HTML 리포트 메일로 받도록 n8n 노드 추가

2026.10문인화 자동 배경 제거
소개:문인화 사진의 배경을 자동으로 지우는 웹 도구
AI:Claude (이미지 처리 코드 작성)
담당:기획, 요구사항 정의, UI/UX 디자인, 테스트, 코드 수정
핵심:
  • 수작업으로 진행하던 사진 편집 6단계를 1단계로 자동화
  • 포토샵 배경 지우기는 흰 테두리가 남고 옅은 부분까지 지워 직접 제작
  • AI가 만든 첫 버전이 종이 뒤 배경까지 종이로 인식하는 문제 발견해결: 사진 46장 중 실패한 사진을 유형별로 나눠 기준 수정, 성공 26장 → 34장으로 개선
  • 처리 시간을 CSV로 기록해 사진마다 편차를 발견하고 원인을 물어 개선결과: 가장 느린 계산을 고쳐 평균 처리 시간 33% 단축
  • API를 쓰지 않아 비용 없이 계속 이용 가능

2026.11스토리형 AI 캐릭터 채팅
소개:내가 고른 말과 행동에 따라 장면, 호감도, 결말이 달라지는 스토리형 AI 캐릭터 채팅
AI:Claude (코드 작성), OpenAI API, Claude API (캐릭터 대화)
기술:React, FastAPI, MySQL, Vercel, Render, TiDB Cloud, Resend
담당:기획, 캐릭터와 장면 설계, 프롬프트 작성, 직접 플레이 테스트, 디자인, 배포와 운영
핵심:
  • 스토리 흐름과 장면 11개, 엔딩 3종을 기획하고, 화면과 서버를 구현해 월 비용 없이 배포
  • 캐릭터 설정과 프롬프트 기획, ChatGPT로 일러스트 15개 생성
  • 사용자가 따르기만 하면 캐릭터가 같은 명령을 반복해 장면이 멈춤해결: 순응하면 새 사건을 벌이는 규칙을 넣고, 장면이 끝나는 조건을 구체화
  • 사용자의 말을 다른 인물의 말로 쓰는 오류 발견해결: 주어 없는 입력은 사용자의 행동으로 보는 규칙 추가
  • 어색한 말투의 원인을 추적해 충돌하는 프롬프트 규칙 직접 정리결과: 프롬프트 약 340자 감소로 API 사용량 절감

담당:수집 설계, 전처리, 분석, 결과 검증
핵심:
  • 상세 페이지 값이 비어서 수집되지 않는 문제 발견해결: 개발자 도구에서 화면이 데이터를 받아 오는 내부 API를 찾아 직접 호출
  • 저장한 데이터를 직접 열어 태그 누락 오류 발견 후 수정
  • 요청을 5건씩 동시에 보내 6분 이상에서 약 30초로 단축
  • AI가 그린 상자그림이 한눈에 안 읽혀 가장 적합한 차트인지 검토 요청결과: 장르별 독자 성향이 바로 보이는 사분면 차트로 변경
  • AI가 나눈 태그 군집이 뚜렷하지 않아 다시 나누도록 지시결과: 모듈러리티 Q 0.25 → 0.37, 4개 군집으로 확정

2026.08웹소설 감상 자동 정리 시스템
소개:자유롭게 쓴 감상을 자동으로 분류하고 검색하는 시스템
AI:ChatGPT (코드 구현), OpenAI API (감상 정리)
담당:문제 정의, 사용 흐름 설계, 프롬프트 규칙 설계, JSON 데이터 구조 설계, 검색 기능 구현, 테스트
핵심:
  • 감상을 입력하면 AI가 인물, 줄거리, 감상으로 나눠 자동 저장
  • 같은 인물의 다른 호칭을 하나의 이름으로 통일예: 진나솔, 진나솔 대리, 나솔이 → 진나솔
  • AI가 감상에 없는 줄거리를 지어내는 문제 발견해결: 없는 내용은 쓰지 않도록 프롬프트 규칙 추가
  • 감상이 길수록 응답이 느려지는 것 확인대응: 원인을 찾기 위해 요청마다 토큰과 응답 시간을 JSON으로 기록
